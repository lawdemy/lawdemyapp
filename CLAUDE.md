# Lawdemy

## Business
Lawdemy is a law education service based in Lagos, with 5 years of experience teaching law practice.

## Audience
Recent law graduates and anyone learning law who wants to stay up to date.
- Primary CTA: Join the Academy
- Secondary CTA: contact form

Design and build for both mobile and web.

## Design
- Accent color: burnt orange
- Use the 60/30/10 color rule
- Font: Poppins
- Color tokens live in `app/globals.css` — use them, don't hardcode colors

## Tech stack
- Next.js (App Router)
- Tailwind CSS
- TypeScript
- Deploys to Vercel

## Rules
- Mobile-first: design and implement for mobile first, then scale up
- Real copy only — never lorem ipsum or placeholder text
- Accessible contrast (meet WCAG AA at minimum)
- Never invent reviews, testimonials, ratings, or certifications — only use real ones with permission
- All business details (contact info, programme details, fees, links) live in `lib/site.ts` — keep it as the single source of truth
